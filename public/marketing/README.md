# Marketing images

Drop files here and the home page uses them automatically (no code change).
If a file is missing, the page shows the built-in illustrated preview instead.

Name (any one extension: .webp, .png, .jpg):

| File        | Where                         | Suggested size | Content                                   |
| ----------- | ----------------------------- | -------------- | ----------------------------------------- |
| `dashboard` | Hero, right side              | 1600x1000      | Real dashboard overview screenshot        |
| `form`      | Registration row              | 1400x900       | Registration form builder screenshot      |
| `checkin`   | Check-in row                  | 1400x900       | Photo or screenshot of QR check-in       |
| `sponsors`  | Sponsors row                  | 1400x900       | Sponsor packages / leads screenshot       |
| `pilot`     | Dark pilot band, left side    | 1400x800       | Event / crowd photo (you must own rights) |

Screenshots: use a demo event with realistic but fake data, and crop out your own email and any real attendee names.
